# Farzeen Sajjad - Portfolio

My personal portfolio site. One HTML file, no build step, no framework: just something I wanted to actually finish and ship.

**Live:** [farzeen-sajjad-portfolio-ius9.vercel.app](https://farzeen-sajjad-portfolio-ius9.vercel.app/)

## What's on it

- **Intro terminal:** a small typing animation with a quick "whoami" style summary
- **Stack:** the tools I actually use, pulled straight from the projects below
- **Projects:** seven things I've built, from CRUD APIs to agentic AI
- **A little agent:** a chat box you can ask about my work. It's rule-based right now (keyword matching against a set of answers I wrote), so it's instant and free to run. No API calls, no backend
- **Contact:** email, GitHub, LinkedIn

## Why it's one file

I wanted the whole thing to be simple to host or fork without thinking about tooling. Everything, markup, styles, and the JS that powers the typing intro, the project cards, and the chat, lives in `index.html`.

## Tech

- HTML / CSS / vanilla JS
- Google Fonts: Space Grotesk, Inter, JetBrains Mono
- The "agent" is a simple keyword-matching bot written directly in the page's script. My actual AI project, the [Job Fit Agent](https://job-fit-agent-8mbusnxecu7m2yvefsqkec.streamlit.app/), is linked from the site and runs on the Gemini API separately
